Script functions are the building blocks for automations written with the [`@workflow` decorator](/sdk-reference/caching). Each function maps directly to a [workflow block](/multi-step-automations/workflow-blocks-reference) and can be `await`-ed inside an `async` script body.

Import them from the top-level `skyvern` package:

```python
from skyvern import (
    action, extract, login, run_task,
    download, goto, http_request,
    conditional, loop, prompt,
    validate, wait, run_code,
    parse_file, parse_pdf,
    send_email, upload_file,
    render_template, render_list,
)
```

<Note>
Script functions must be called inside an `async` function decorated with `@workflow`. They rely on Skyvern's internal run context and will raise exceptions if called outside a running workflow.
</Note>

## run_task

Run a navigation task. The AI agent browses to `url` and takes actions until the `prompt` goal is met.

```python
async def run_task(
    prompt: str,
    url: str | None = None,
    max_steps: int | None = None,
    download_suffix: str | None = None,
    totp_identifier: str | None = None,
    totp_url: str | None = None,
    label: str | None = None,
    cache_key: str | None = None,
    engine: RunEngine = RunEngine.skyvern_v1,
    model: dict | None = None,
    error_code_mapping: dict[str, str] | None = None,
) -> dict | list | str | None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `prompt` | `str` | — | **Required.** Natural language navigation goal. Include COMPLETE/TERMINATE instructions. |
| `url` | `str` | `None` | Starting URL. If omitted, continues from the current page. |
| `max_steps` | `int` | `None` | Maximum AI steps allowed. |
| `download_suffix` | `str` | `None` | Filename for any file downloaded during the task. |
| `totp_identifier` | `str` | `None` | TOTP credential identifier for 2FA. |
| `totp_url` | `str` | `None` | URL to fetch TOTP codes from. |
| `label` | `str` | `None` | Block label for output references and caching. |
| `cache_key` | `str` | `None` | Key for the `@cached` script cache. Defaults to `label`. |
| `error_code_mapping` | `dict` | `None` | Map custom error codes to descriptions. |

<CodeGroup>
```python Python
from skyvern import run_task

result = await run_task(
    prompt="Search for 'AI browser automation' and COMPLETE when results are shown.",
    url="https://www.google.com",
    max_steps=10,
    label="search_google",
)
```
</CodeGroup>

## action

Take a single browser action using the AI agent. Unlike `run_task`, this is intended for precise single actions (one click, one fill) rather than multi-step navigation.

```python
async def action(
    prompt: str,
    url: str | None = None,
    max_steps: int | None = None,
    download_suffix: str | None = None,
    totp_identifier: str | None = None,
    totp_url: str | None = None,
    label: str | None = None,
    cache_key: str | None = None,
    model: dict | None = None,
    error_code_mapping: dict[str, str] | None = None,
) -> None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `prompt` | `str` | — | **Required.** Description of the single action to take. |
| `url` | `str` | `None` | URL to navigate to before the action. |
| `label` | `str` | `None` | Block label for caching. |

<CodeGroup>
```python Python
from skyvern import action

await action(
    prompt='Click the "Download PDF" button',
    label="click_download",
)
```
</CodeGroup>

## extract

Extract structured data from the current page using the AI agent.

```python
async def extract(
    prompt: str,
    schema: dict | list | str | None = None,
    url: str | None = None,
    max_steps: int | None = None,
    label: str | None = None,
    cache_key: str | None = None,
    model: dict | None = None,
) -> dict | list | str | None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `prompt` | `str` | — | **Required.** Description of what data to extract. |
| `schema` | `dict \| list \| str` | `None` | JSON Schema for the output structure. |
| `url` | `str` | `None` | URL to navigate to before extracting. |
| `label` | `str` | `None` | Block label. |

<CodeGroup>
```python Python
from skyvern import extract

data = await extract(
    prompt="Extract the order total, date, and item list from this page.",
    schema={
        "type": "object",
        "properties": {
            "order_total": {"type": "number"},
            "order_date": {"type": "string"},
            "items": {"type": "array", "items": {"type": "string"}},
        }
    },
    label="extract_order",
)
print(data["order_total"])
```
</CodeGroup>

## http_request

Make an HTTP API call.

```python
async def http_request(
    method: str,
    url: str,
    headers: dict[str, str] | None = None,
    body: dict | None = None,
    timeout: int = 30,
    follow_redirects: bool = True,
    label: str | None = None,
    parameters: list[str] | None = None,
) -> None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `method` | `str` | — | **Required.** HTTP method: `GET`, `POST`, `PUT`, `DELETE`, etc. |
| `url` | `str` | — | **Required.** Target URL. |
| `headers` | `dict` | `None` | HTTP headers. |
| `body` | `dict` | `None` | Request body (for POST/PUT). |
| `timeout` | `int` | `30` | Request timeout in seconds. |
| `follow_redirects` | `bool` | `True` | Follow HTTP redirects. |
| `label` | `str` | `None` | Block label. |

<CodeGroup>
```python Python
from skyvern import http_request

await http_request(
    method="POST",
    url="https://api.example.com/notify",
    headers={"Authorization": "Bearer {{api_token}}"},
    body={"status": "completed", "data": "{{extract_order_output}}"},
    label="notify_api",
)
```
</CodeGroup>

## conditional

Evaluate a conditional block using a cached Python function (registered via `@cached`). Returns branch metadata including `next_block_label`.

```python
async def conditional(label: str) -> dict
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `label` | `str` | — | **Required.** Label matching the `@cached` key for the branch function. |

The cached function must return `{"next_block_label": "...", "branch_index": N}`.

<CodeGroup>
```python Python
from skyvern import cached, conditional

@cached("check_status")
async def check_status_fn(page, context):
    status = context.parameters.get("extract_status_output", {}).get("status")
    if status == "approved":
        return {"next_block_label": "process_approved", "branch_index": 0}
    return {"next_block_label": "handle_rejection", "branch_index": 1}

# In the workflow body:
branch = await conditional("check_status")
```
</CodeGroup>

## loop

Iterate over a list of values, yielding a `SkyvernLoopItem` for each iteration.

```python
async def loop(
    values: Sequence | str,
    complete_if_empty: bool = False,
    label: str | None = None,
) -> AsyncGenerator[SkyvernLoopItem, None]
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `values` | `Sequence \| str` | — | **Required.** Sequence (list, tuple, etc.) to iterate over, or a parameter key reference (string) to resolve at runtime. |
| `complete_if_empty` | `bool` | `False` | Complete successfully if the list is empty. |
| `label` | `str` | `None` | Block label. |

Each yielded `SkyvernLoopItem` has:
- `item.current_value` — the current iteration value
- `item.current_index` — the zero-based iteration index
- `item.current_item` — alias for `current_value`

<CodeGroup>
```python Python
from skyvern import loop, run_task

async for item in loop(["https://job1.com", "https://job2.com"], label="job_loop"):
    await run_task(
        prompt="Fill and submit the job application form.",
        url=item.current_value,
        label="submit_application",
    )
```
</CodeGroup>

## prompt

Send a prompt to an LLM and return the response. Useful for text generation, classification, or analysis without browser interaction.

```python
async def prompt(
    prompt: str,
    schema: dict | None = None,
    label: str | None = None,
    parameters: list[str] | None = None,
    model: dict | None = None,
) -> dict | list | str | None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `prompt` | `str` | — | **Required.** The prompt text. Supports Jinja2 templates. |
| `schema` | `dict` | `None` | JSON Schema for structured output. |
| `label` | `str` | `None` | Block label. |
| `model` | `dict` | `None` | Model override configuration. |

<CodeGroup>
```python Python
from skyvern import prompt

summary = await prompt(
    prompt="Summarize the following data and flag any anomalies: {{extract_data_output}}",
    schema={
        "type": "object",
        "properties": {
            "summary": {"type": "string"},
            "anomalies": {"type": "array", "items": {"type": "string"}},
        }
    },
    label="summarize_data",
)
print(summary["summary"])
```
</CodeGroup>

## validate

Assert conditions using the LLM. Raises a termination exception if `terminate_criterion` is met.

```python
async def validate(
    complete_criterion: str | None = None,
    terminate_criterion: str | None = None,
    error_code_mapping: dict[str, str] | None = None,
    label: str | None = None,
    model: dict | None = None,
) -> None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `complete_criterion` | `str` | `None` | Condition to continue. At least one of `complete_criterion` or `terminate_criterion` is required. |
| `terminate_criterion` | `str` | `None` | Condition that terminates the workflow. |
| `error_code_mapping` | `dict` | `None` | Map custom error codes to descriptions. |
| `label` | `str` | `None` | Block label. |

<CodeGroup>
```python Python
from skyvern import validate

await validate(
    complete_criterion="The page shows a confirmation message indicating the form was submitted.",
    terminate_criterion="The page shows an error or the session has expired.",
    label="check_submission",
)
```
</CodeGroup>

## run_code

Execute a Python code snippet. The `result` variable set inside the code is returned.

```python
async def run_code(
    code: str,
    label: str | None = None,
    parameters: list[str] | None = None,
) -> dict[str, Any]
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `code` | `str` | — | **Required.** Python code to execute. Set `result` to return a value. |
| `label` | `str` | `None` | Block label. |
| `parameters` | `list[str]` | `None` | Parameter keys to make available. |

<CodeGroup>
```python Python
from skyvern import run_code

output = await run_code(
    code="result = {'total': sum(prices)}",
    parameters=["prices"],
    label="sum_prices",
)
```
</CodeGroup>

## send_email

Send an email with optional file attachments.

```python
async def send_email(
    sender: str,
    recipients: list[str] | str,
    subject: str,
    body: str,
    file_attachments: list[str] = [],
    label: str | None = None,
    parameters: list[str] | None = None,
) -> None
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `sender` | `str` | — | **Required.** Sender email address. |
| `recipients` | `list[str] \| str` | — | **Required.** Recipient(s). |
| `subject` | `str` | — | **Required.** Email subject. |
| `body` | `str` | — | **Required.** Email body. |
| `file_attachments` | `list[str]` | `[]` | File paths to attach. Use `SKYVERN_DOWNLOAD_DIRECTORY` for downloaded files. |

<Note>
SMTP parameters (`smtp_host`, `smtp_port`, `smtp_username`, `smtp_password`) must be defined as workflow parameters.
</Note>
