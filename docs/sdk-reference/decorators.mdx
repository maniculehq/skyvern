The Skyvern Python SDK ships a set of decorators and top-level script functions that let you write browser automation as plain Python functions. This is the **script-based** API — an alternative to calling `client.run_task()` — that gives you fine-grained control over execution flow, caching, and reuse.

If you want inline AI calls within an existing Playwright script without the script-based control flow, use [SkyvernPage](/sdk-reference/skyvern-page) directly instead.

All decorators and functions are exported directly from the `skyvern` package:

```python
from skyvern import workflow, cached
from skyvern import setup, action, conditional
from skyvern import goto, extract, run_task, login, download, validate, wait
# ... and more
```

---

## Decorators

### `@workflow`

Declares a Python function as a Skyvern workflow. Attaches metadata that the runtime uses when the function is registered or executed.

```python
from skyvern import Skyvern, workflow, SkyvernPage, RunContext

@workflow(
    title="Monthly Invoice Downloader",
    max_steps=50,
    webhook_url="https://my-app.com/hooks/skyvern",
)
async def download_invoices(page: SkyvernPage, context: RunContext) -> None:
    await page.goto("https://billing.example.com")
    await page.agent.login(credential_id=context.parameters["cred_id"])
    await page.agent.download_files("Download all invoices from January 2025")
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `title` | `str \| None` | `None` | Human-readable name displayed in the Skyvern UI |
| `totp_url` | `str \| None` | `None` | URL used to poll for TOTP codes during this workflow |
| `totp_identifier` | `str \| None` | `None` | Identifier for TOTP polling |
| `webhook_url` | `str \| None` | `None` | Default webhook for run-status notifications |
| `max_steps` | `int \| None` | `None` | Global step cap for AI agent tasks within this workflow |

<Note>
`@workflow` is currently a **metadata hint**, not an enforced runtime contract. At execution time the decorator is a no-op that returns the original function unchanged — it does not register the function, trigger a workflow run, or validate parameters automatically. The metadata you pass (`title`, `max_steps`, etc.) is used by tooling and the Skyvern UI when the script is uploaded or referenced, but does not affect in-process execution.
</Note>

### `@cached`

Marks a block of a script as cacheable by a string key. The labelled block can be replayed or skipped during script development and debugging without re-running earlier steps.

```python
from skyvern import cached, SkyvernPage, RunContext

@cached("navigate-to-reports")
async def navigate_to_reports(page: SkyvernPage, context: RunContext) -> None:
    await page.goto("https://app.example.com/reports")
    await page.wait_for_selector(".report-list")
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `cache_key` | `str` | Unique identifier for this block within the script |

<Note>
`@cached` sets `page.current_label = cache_key` before the wrapped function runs, and **always** clears it (via `finally`) after — even if the function raises an exception. This label is what the Skyvern runtime uses to identify, replay, or skip the block. If your cached function itself raises, the label is still cleared and the exception propagates normally.
</Note>

## Script initialization

### `setup()`

Initializes a Skyvern script session. Call this at the entry point of your script to obtain a `SkyvernPage` and a `RunContext` bound to the active browser session.

```python
from skyvern import setup, SkyvernPage, RunContext

async def main() -> None:
    page, context = await setup(parameters={"cred_id": "cred_abc123"})
    await my_workflow(page, context)
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `parameters` | `dict` | — | Key-value pairs accessible in the workflow via `context.parameters` |
| `generated_parameter_cls` | `type[BaseModel] \| None` | `None` | Pydantic model class for typed parameter validation |
| `browser_session_id` | `str \| None` | `None` | Attach to an existing browser session instead of creating a new one |
| `adaptive_caching` | `bool` | `False` | Enable adaptive cache replay during script development |

Returns `tuple[SkyvernPage, RunContext]`.

**`context.parameters` is a safe-access dict**

`RunContext.parameters` behaves like a regular `dict` with one difference: accessing a key that doesn't exist returns `None` and logs a warning instead of raising a `KeyError`. This prevents cached scripts from crashing when a parameter key is renamed or removed, but it means typos in parameter names fail silently. Always verify parameter names when debugging unexpected `None` values.

```python
# This does NOT raise KeyError — returns None and logs a warning instead
value = context.parameters["typo_key"]
```

**`adaptive_caching` and performance**

When `adaptive_caching=True`, `setup()` makes a single LLM call to extract canonical values from your `parameters` dict before the workflow runs. This result is cached for **1 hour** (up to 256 entries by SHA-256 key). Only string parameters longer than 100 characters are sent to the LLM; short strings and non-string values are matched directly by key name. If the LLM call fails, execution continues without the extracted values — no exception is raised.

## Conditional branching

### `conditional()`

Evaluates a conditional branch defined by a `@cached` function registered under the given label. The cached function must return a dict with `next_block_label` indicating which branch to follow.

```python
from skyvern import cached, conditional, SkyvernPage, RunContext

# Register a branch function with @cached
@cached("check-login")
async def check_if_logged_in(page: SkyvernPage, context: RunContext) -> dict:
    logged_in = await page.validate("The user is logged in")
    return {
        "next_block_label": "post-login" if logged_in else "do-login",
        "branch_index": 0 if logged_in else 1,
    }

# Evaluate the branch inside a workflow
async def my_workflow(page: SkyvernPage, context: RunContext) -> None:
    result = await conditional("check-login")
    # result["next_block_label"] tells the runtime which block to run next
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `label` | `str` | The `cache_key` of the `@cached` function that evaluates the branch |

Returns `dict[str, Any]` with at minimum `next_block_label` and `branch_index`.

## Action functions

These top-level functions are the building blocks of Skyvern scripts. Each maps to a single browser or AI operation and is designed to be called inside a `@workflow` or `@cached` function.

### Browser navigation

| Function | Description |
|----------|-------------|
| `goto(url)` | Navigate to a URL |
| `wait(seconds)` | Pause execution |

### AI actions

| Function | Description |
|----------|-------------|
| `extract(prompt, schema?)` | Extract structured or unstructured data from the page |
| `validate(complete_criterion?, terminate_criterion?)` | Check completion or termination conditions; returns without error if condition holds |
| `prompt(prompt, schema?)` | Raw LLM call with page context |

### Task execution

| Function | Description |
|----------|-------------|
| `action(prompt, **kwargs)` | Run a single AI navigation action (supports caching via `cache_key`) |
| `run_task(prompt, **kwargs)` | Run a full multi-step AI task — see [Tasks](/sdk-reference/tasks) for parameters |
| `run_script(script_id, **kwargs)` | Run a stored script by ID |
| `run_code(code, **kwargs)` | Execute a code block |

### Authentication

| Function | Description |
|----------|-------------|
| `login(credential_id, **kwargs)` | Log in using a stored credential — see [Credentials](/sdk-reference/credentials) |

### File operations

| Function | Description |
|----------|-------------|
| `download(prompt, **kwargs)` | Download files matching a description |
| `parse_file(file_path, **kwargs)` | Parse a local file and return its content |
| `parse_pdf(file_path, **kwargs)` | Parse a PDF and return structured content |
| `upload_file(file_path, **kwargs)` | Upload a file to the current page |

### Data rendering

| Function | Description |
|----------|-------------|
| `render_list(items, template)` | Render a Jinja2 template over a list |
| `render_template(template, **kwargs)` | Render a single Jinja2 template |

### Communication

| Function | Description |
|----------|-------------|
| `send_email(sender, recipients, subject, body, ...)` | Send an email from `sender` to one or more `recipients` |
| `http_request(method, url, ...)` | Make an outbound HTTP request |

### Control flow

| Function | Description |
|----------|-------------|
| `loop(values, complete_if_empty?, label?)` | Async generator — yields `SkyvernLoopItem` for each value; use with `async for` |

## End-to-end example

```python
import asyncio
from skyvern import SkyvernPage, RunContext
from skyvern import workflow, cached, setup

@cached("login-step")
async def do_login(page: SkyvernPage, context: RunContext) -> None:
    await page.agent.login(credential_id=context.parameters["cred_id"])

@workflow(title="Q1 Report Collector", max_steps=100)
async def collect_reports(page: SkyvernPage, context: RunContext) -> None:
    await page.goto("https://portal.example.com")
    await do_login(page, context)

    reports = await page.extract(
        "List all Q1 2025 reports with their download links",
        schema={
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "name": {"type": "string"},
                    "url":  {"type": "string"},
                },
            },
        },
    )

    for report in reports:
        await page.goto(report["url"])
        await page.agent.download_files("Download the report file")

async def main() -> None:
    # setup() initialises the browser session and returns (page, context)
    page, context = await setup(parameters={"cred_id": "cred_abc123"})
    await collect_reports(page, context)

asyncio.run(main())
```
