---
title: "get_folders"
description: "List every folder in the organization with workflow counts and optional search."
slug: sdk-reference/folders/list-folders
---

The list endpoint paginates folders for the calling org. Each folder includes a precomputed `workflow_count`, so a UI can render a sidebar of folders without one round-trip per folder.

<CodeGroup>
```python Python
folders = await client.get_folders(page=1, page_size=100, search="invoice")
for f in folders:
    print(f.folder_id, f.title, f.workflow_count)
```

```typescript TypeScript
const folders = await skyvern.getFolders({ page: 1, pageSize: 100, search: "invoice" });
for (const f of folders) {
  console.log(f.folder_id, f.title, f.workflow_count);
}
```
</CodeGroup>

The result is a flat list. Empty folders are returned with `workflow_count = 0`.

### Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `page` | `int` | No | `1` | 1-indexed page number. |
| `page_size` | `int` | No | `100` | Items per page, max `500`. |
| `search` | `str \| None` | No | `None` | Case-insensitive substring match against title and description. |
| `request_options` | `RequestOptions` | No | - | Per-request configuration (see below). |

### Returns `list[Folder]`

Each `Folder` carries `folder_id`, `organization_id`, `title`, `description`, `workflow_count`, `created_at`, and `modified_at`.

### Example: page through every folder

<CodeGroup>
```python Python
page = 1
all_folders = []
while True:
    batch = await client.get_folders(page=page, page_size=500)
    if not batch:
        break
    all_folders.extend(batch)
    if len(batch) < 500:
        break
    page += 1
```

```typescript TypeScript
let page = 1;
const all = [];
while (true) {
  const batch = await skyvern.getFolders({ page, pageSize: 500 });
  if (batch.length === 0) break;
  all.push(...batch);
  if (batch.length < 500) break;
  page += 1;
}
```
</CodeGroup>

### Request options

Override timeout, retries, or headers for this call by passing `request_options` (Python) or a second options argument (TypeScript).

<CodeGroup>
```python Python
from skyvern.client.core import RequestOptions

request_options = RequestOptions(
    timeout_in_seconds=120,
    max_retries=3,
    additional_headers={"x-custom-header": "value"},
)
```

```typescript TypeScript
{
  timeoutInSeconds: 120,
  maxRetries: 3,
  headers: { "x-custom-header": "value" },
}
```
</CodeGroup>

| Option (Python) | Option (TypeScript) | Type | Description |
|-----------------|---------------------|------|-------------|
| `timeout_in_seconds` | `timeoutInSeconds` | `int` / `number` | HTTP timeout in seconds. |
| `max_retries` | `maxRetries` | `int` / `number` | Retry count. |
| `additional_headers` | `headers` | `dict` / `Record<string, string>` | Extra headers. |
| `additional_query_parameters` | - | `dict` | Extra query parameters. |
| `additional_body_parameters` | - | `dict` | Extra body parameters. |
| - | `abortSignal` | `AbortSignal` | Signal to cancel the request. |
| - | `apiKey` | `string` | Override API key. |
