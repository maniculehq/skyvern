Use this endpoint when you already know which workflow you care about and want every schedule that fires it. For a single org-wide view, see [`schedules_list_all`](./list-all-schedules).

<Note>
Schedules require Skyvern Cloud (or a self-hosted build with a scheduling backend). When disabled the endpoint returns `501 Not Implemented`.
</Note>

<CodeGroup>
```python Python
resp = await client.schedules_list(workflow_permanent_id="wpid_invoices")
for s in resp.schedules:
    print(s.cron_expression, s.timezone, "enabled" if s.enabled else "paused")
```

```typescript TypeScript
const resp = await skyvern.schedulesList("wpid_invoices");
for (const s of resp.schedules) {
  console.log(s.cron_expression, s.timezone, s.enabled ? "enabled" : "paused");
}
```
</CodeGroup>

The result is unpaginated. A single workflow has at most a small number of schedules (the create endpoint enforces a per-workflow limit), so the full set always fits in one response.

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workflow_permanent_id` | `str` | Yes | The workflow's permanent id (`wpid_...`). |
| `request_options` | `RequestOptions` | No | Per-request configuration (see below). |

### Returns `WorkflowScheduleListResponse`

| Field | Type | Description |
|-------|------|-------------|
| `schedules` | `list[WorkflowSchedule]` | All schedules attached to the workflow, including paused ones. |

Each `WorkflowSchedule` includes `workflow_schedule_id`, `cron_expression`, `timezone`, `enabled`, `parameters` (the override map), `name`, `description`, the wire-format `temporal_schedule_id` (alias of `backend_schedule_id`), `created_at`, and `modified_at`.

### Errors

- `404 Not Found` — `Workflow {wpid} not found`. Check the workflow id is correct and belongs to the calling org.
- `501 Not Implemented` — Scheduling is disabled in this build.

### Related

- [`schedules_create`](./create-schedule) — add a schedule to this workflow.
- [`schedules_list_all`](./list-all-schedules) — the org-wide list.
